# 22차시 웹 접근성 점검 보고서

## 1. 개요
* **점검 대상**: 메인 페이지 (`index.html`), 상세 페이지 (`detail.html`), 신청 폼 페이지 (`apply.html`)
* **점검 일시**: 2026년 9월 29일
* **점검 도구**: Chrome DevTools Lighthouse (Accessibility 카테고리) 및 수동 키보드/라벨 클릭 점검

---

## 2. 접근성 3대 항목 수동 점검 결과

### ① 대체 텍스트 (`alt` 속성) 점검
* **점검 결과**: **적합 (Pass)**
* **상세 내용**:
  * 단순 "사진", "이미지" 등의 포괄적 단어가 아닌 구체적 설명 텍스트 적용 확인
  * 예시: `alt="스무 살의 첫 이력서 워크숍 현장 사진"`, `alt="시청각실 공간 전경 사진"`
  * 장식용/의미 없는 아이콘 및 그래픽은 `aria-hidden="true"` 속성으로 스크린 리더 제외 처리

### ② 라벨 연결 (`<label for="">` & `<input id="">`) 점검
* **점검 결과**: **적합 (Pass)**
* **상세 내용**:
  * 신청 폼 내 7개 전체 입력 항목의 `label` 클릭 시 해당 입력창으로 포커스 정상 이동 확인
  * 개인정보 동의 체크박스(`agree`) 텍스트 클릭 시 체크박스 토글 정상 작동 완료
  * 희망 좌석 라디오 버튼 및 입력 항목 간 `for`-`id` 매핑 100% 일치 확인

### ③ 색 대비 (Color Contrast) 및 키보드 접근성 점검
* **점검 결과**: **적합 (Pass)**
* **상세 내용**:
  * `tokens.css` 내 기본 글자색(`--ink: #14161c`)과 배경색(`--paper: #ffffff`)의 명암비가 **4.5:1 이상** 기준 만족
  * `*:focus` 지우기(`outline: none`) 코드를 절대 사용하지 않아 `Tab` 키 이동 시 블루 아웃라인(Focus Ring) 정상 표출 확인

## 4. 접근성 개선 조치 사항 요약

1. **Heading 구조 단계를 순차적으로 정돈 (`h1` ➔ `h2` ➔ `h3`)**
   * 헤딩 태그를 건너뛰지 않고 계층 구조에 맞게 순서를 고침
2. **보조 글자 색상 명암비 상향 조정 (`tokens.css`)**
   * 대비 부족 지적 가능성이 있던 연한 회색 보조 텍스트 색상을 더 진한 색으로 조정하여 시인성 확보
3. **키보드 포커스 링 보존**
   * 마우스를 쓰지 않는 키보드 전용 사용자를 위해 아웃라인 삭제 스타일 금지 규칙 준수
