## 5. 발견된 결함 목록 (상대 팀 전달용)

1. **[DEF-01] 이름 항목 공백 처리 미흡 (TC-02)**
   * **설명**: 이름 입력란에 공백문자(` `)만 입력 후 제출 시 에러가 발생하지 않고 신청 완료 화면으로 넘어가 버림 (`.trim()` 검증 누락 추정).
2. **[DEF-02] 참가 인원 최솟값 경계 검증 오류 (TC-12)**
   * **설명**: 참가 인원에 `0`을 입력 시 통과되어 완료 화면에 `0명`으로 출력됨 (`min="1"` 조건 미적용).
3. **[DEF-03] 모바일 반응형 반응 불량 (UI 체크리스트 6번)**
   * **설명**: 화면 너비를 375px(모바일)로 줄였을 때 메인 카드 목록이 1열로 바뀌지 않고 3열 구조를 유지하여 화면 밖으로 넘침.
